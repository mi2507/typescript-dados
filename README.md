# 📊 Estatísticas de Transações — TypeScript

Projeto desenvolvido como exercício prático durante o curso de TypeScript da Origamid, com foco em consumo de API REST, manipulação de dados e cálculo de estatísticas.

## 🎯 Objetivo

Consumir dados de transações disponibilizados por uma API, organizar as informações em uma tabela e apresentar estatísticas para facilitar a visualização dos dados.

## ✨ Funcionalidades

- Consumo de dados de uma API REST.
- Exibição das transações em uma tabela.
- Formatação de valores monetários em reais (BRL).
- Cálculo do valor total das transações.
- Contagem de transações por meio de pagamento.
- Contagem de transações por status.
- Agrupamento de vendas por dia da semana.
- Identificação do dia da semana com maior volume de vendas.
- Organização da lógica em módulos TypeScript.

## 🛠️ Tecnologias utilizadas

- **TypeScript** — tipagem estática e organização da lógica.
- **JavaScript** — manipulação de dados.
- **HTML5** — estrutura da página.
- **CSS3** — apresentação visual.
- **API REST / JSON** — obtenção e tratamento dos dados.
- **Git e GitHub** — versionamento do código.

## 🔗 API utilizada

Os dados são obtidos da API disponibilizada pela Origamid:

https://api.origamid.dev/json/transacoes.json

## ▶️ Como executar o projeto

### Pré-requisitos

- Node.js e npm instalados.
- Git instalado.
- Um editor de código, como o Visual Studio Code.

### Instalação e execução

1. Clone o repositório:

   ```bash
   git clone URL_DO_SEU_REPOSITORIO
   ```

2. Acesse a pasta do projeto:

   ```bash
   cd TypeScript-Dados
   ```

3. Instale as dependências, caso o projeto tenha um `package.json` com dependências configuradas:

   ```bash
   npm install
   ```

4. Compile os arquivos TypeScript:

   ```bash
   npx tsc
   ```

5. Abra o arquivo `index.html` utilizando o Live Server do Visual Studio Code para visualizar a aplicação.

> **Observação:** o projeto utiliza uma API externa. O carregamento dos dados depende da disponibilidade da API e das permissões de acesso do navegador.
